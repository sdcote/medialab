# Workflows
This is my personal workflow for a few common tasks.

# There is a PROBLEM on MacOS
Date and time data does not seem to be preserved when moving files from the iPhone to the Mac.

## iPhone Media
1. ImageCapture to the Phone folder !!!VERIFY TIMESTAMPS!!!
1. `snap FileClassifier` to move IMG_\d files to either Images or Videos !!!VERIFY TIMESTAMPS!!!
1. Check remaining files...these are probably image downloads from other apps
1. `snap MDCimages` places all the images into date subfolders and moves them into Pictures
1. `snap MDCvideos` places all the videos into date subfolders and moves them into Videos
1. Check the Images directory to make sure everything has been classified
1. Check the Videos directory to make sure everything has been classified
